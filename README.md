# Carnage Party

Полноценный мессенджер в стиле Discord на **Electron + React**. Сервер работает локально внутри приложения, интернет для общения не нужен — но ник и голосовые комнаты работают по-настоящему, через WebRTC.

> твоя стая, твой голос, твоя вечеринка

---

## Что умеет

- **Серверы и каналы** — текстовые и голосовые, создание, настройка, удаление, приглашения по коду.
- **Роли и права** — гибкие разрешения, цветные роли, иерархия, выдача ролей участникам; создатель сервера может назначать роли прямо из списка участников.
- **Модерация** — кик, бан, разбан, список банов, удаление сообщений; серверный мут, который администратор включает из списка участников или голосового канала и который действует для всех. Обычный участник может заглушить конкретного человека только у себя.
- **Музыкальные боты** — любой участник сервера может включить бота в голосовом канале, сменить трек, поставить паузу, перемотать и остановить музыку. YouTube, Rutube, VK Видео и ссылки VK Music играют через серверный поток, поэтому работают ролики с запретом встраивания. Плеер каждый перетаскивает у себя независимо, позиция сохраняется локально, двойной клик возвращает его в угол.
- **Друзья** — заявки, принятие/отклонение, удаление, поиск пользователей, статусы.
- **Личные сообщения** — диалоги и группы, настройки, история, непрочитанные.
- **Сообщения** — редактирование, удаление, ответы, упоминания, реакции, закрепление, вложения (фото, видео, аудио, файлы), эмодзи-пикер и кругляши — видео с камеры и микрофона до 60 секунд с круглым предпросмотром и воспроизведением по клику.
- **Голос и видео** — голосовые каналы, камера, демонстрация экрана с выбором монитора (превью всех экранов), звуковые индикаторы, звонки в ЛС (WebRTC mesh, сигналинг через Socket.IO, TURN и ICE для работы за NAT). Участники и боты в голосовом канале кликабельны: открывается профиль или окно музыки, а по правому клику — действия модерации.
- **Watch Party** — совместный просмотр YouTube, VK Видео и прямых видео: синхронные пауза, перемотка и позиция, ожидание зрителей во время буферизации хоста, чат комнаты со смайлами и локальный звук у каждого участника. Встроенный браузер открывает YouTube-видео с запретом встраивания и любые другие сайты; ссылку может сменить любой участник, а приглашение копируется одной кнопкой.
- **Мультистрим** — одновременная трансляция в Carnage Party, Twitch, YouTube и VK Live через встроенный ffmpeg; ключи площадок шифруются на компьютере.
- **Режим рации** — push-to-talk: микрофон включается только пока вы удерживаете назначенную клавишу или кнопку «Рация» в голосовой комнате и Watch Party.
- **Поиск** — глобальный (`Ctrl+K`) и по каналу.
- **Интерфейс** — тёмная тема, компактный режим, уведомления, push-уведомления о новых сообщениях и упоминаниях, горячие клавиши, адаптивная вёрстка.
- **Локальные данные** — SQLite с полнотекстовым поиском по истории сообщений, загрузки в папке данных, JWT-авторизация, bcrypt-хэши паролей.

## Быстрый старт

1. Запустите **`carnage.bat`** — откроется единое меню.
2. Пункт **1** — установить зависимости (нужно один раз).
3. Пункт **2** — собрать интерфейс и запустить приложение.
4. Зарегистрируйте аккаунт на экране входа — демо-данные в поставку не входят.

Для запуска без BAT-файла:

```powershell
npm run setup
npm start
```

## Единое меню `carnage.bat`

Все действия выполняются через один файл **`carnage.bat`** в корне проекта.
Двойной клик открывает меню с нумерованными разделами:

| Пункт | Что делает |
|-------|------------|
| 1 | Установка зависимостей (`npm install` + клиент) |
| 2 | Сборка клиента и запуск Electron (порт 32456) |
| 3 | Режим разработки: Vite 5173 + сервер 3001 + Electron |
| 4 | Локальный сервер на `http://127.0.0.1:3001` |
| 5 | Сервер для локальной сети (`0.0.0.0`) |
| 6 | Подключение Electron-клиента к внешнему серверу |
| 7 | Сборка React-клиента в `client\dist` |
| 8 | Сборка установщика NSIS |
| 9 | Сборка переносной portable-версии |
| 10 | Сборка Windows: Setup + Portable |
| 11 | Сборка Android APK |
| 12 | Полная сборка: Windows + Android |
| 13 | Раскладка обновлений в `updates` и SHA256 |
| 14 | Открыть папку `release` |
| 15 | Открыть папку `updates` |
| 16 | Очистить `release`, `client\dist`, `dist` |
| 17 | Проверка окружения: Node/npm, зависимости, порты |
| 18 | Показать физический IP без VPN |
| 0 | Выход |

> `carnage.bat` сохранён с переводами строк CRLF — так же должны сохраняться
> любые новые BAT-файлы.

## Готовые сборки

После пункта **10** (или `npm run dist`) в папке `release`:

```
release\Carnage-Party-Setup-1.2.3.exe      — установщик NSIS
release\Carnage-Party-Portable-1.2.3.exe   — переносная версия
release\Carnage-Party-Portable-1.2.3.zip   — ZIP для автообновления portable
release\Carnage-Party-Mobile-1.2.3.apk     — Android
```

Установщик позволяет выбрать папку, создаёт ярлыки на рабочем столе и в меню «Пуск».

### Сборка релиза

1. Пункт **10** — собрать Windows (Setup + Portable).
2. Пункт **11** — собрать Android APK.
3. Пункт **13** — разложить файлы в `updates` и посчитать SHA256.

Отдельных BAT-файлов для сборки больше нет — всё выполняется через
`carnage.bat`.

### Трей, темы и звук трансляции

- Закрытие окна установленной или portable-версии сворачивает приложение в
  трей. Правый клик по значку — «Развернуть» или «Закрыть».
- Тема по умолчанию — чёрно-серая. Прежняя тёмно-сливовая палитра доступна
  в **Настройки → Внешний вид → Carnage**.
- При просмотре чужой трансляции справа внизу плеера есть отдельный
  ползунок громкости и кнопка выключения звука — он не влияет на голос
  участников.

**Данные приложения** (база, аватары, вложения) хранятся на сервере:

```
data\
```

Установленная, portable и Android-версии подключаются к внешнему серверу
(`carnage.bat`, пункты 4 или 5). Если сервер выключен, приложение
показывает экран «Сервер выключен или недоступен». Локальный сервер внутри
установленной и portable-версии больше не запускается — он остаётся только
для пункта 2 (`npm start`) при запуске из исходников.

## Автообновление

При запуске клиент определяет свою платформу и запрашивает у сервера
`/api/version`. Если на сервере лежит версия новее текущей, появляется окно
«Доступно обновление» с changelog.

Обновления кладутся в папку `updates` (перезапуск сервера не нужен):

```
updates\Carnage-Party-Setup-X.Y.Z.exe      — установленная версия Windows
updates\Carnage-Party-Portable-X.Y.Z.zip   — portable (ZIP с exe внутри)
updates\Carnage-Party-Mobile-X.Y.Z.apk     — Android
updates\changelog.json                     — {"X.Y.Z": ["что нового", ...]}
```

Как происходит установка:

- **Установленная версия** — скачивает Setup с прогрессом, закрывается,
  тихо переустанавливается поверх текущей версии и открывается снова.
  Данные и настройки сохраняются.
- **Portable** — скачивает ZIP, заменяет новые и изменённые файлы в своей
  папке, удаляет старый exe и перезапускается.
- **Android** — скачивает APK внутри приложения и открывает системный
  установщик.

Проверить обновление вручную можно в **Настройки → Обновления**: там видны
текущая версия и платформа, кнопка «Проверить обновления», кнопка
«Обновить» с прогрессом и список изменений. После установки новой версии
при первом запуске один раз показывается окно «Что нового».

Установленная, portable и Android-версии подключаются к внешнему серверу и
берут обновления из его папки `updates`. Если сервер выключен, проверка
обновлений не выполняется — приложение показывает экран недоступного сервера.

## Порты и режимы

| Режим | Клиент | API / Socket.IO | Данные |
|-------|--------|-----------------|--------|
| `carnage.bat`, пункт 2 / `npm start` | раздаётся Electron-сервером | `127.0.0.1:32456` (+7 при занятости) | `%APPDATA%\Carnage Party\data` |
| Установленная / portable / Android | раздаётся внешним сервером | `188.234.161.207:3001` (по умолчанию) | `data\` на сервере |
| `carnage.bat`, пункт 3 | Vite `http://localhost:5173` | `127.0.0.1:3001` | `data-dev\` |
| `carnage.bat`, пункт 4 | `http://127.0.0.1:3001` | `127.0.0.1:3001` | `data\` |
| `carnage.bat`, пункт 5 | `http://<IP-хоста>:3001` | `0.0.0.0:3001` | `data\` |

Сменить базовый порт Electron можно переменной окружения:

```powershell
set CARNAGE_PORT=32500
npm start
```

Если порт занят, приложение автоматически пробует следующие 7 портов.

## Подключение с других ПК

По умолчанию пункт 2 `carnage.bat` поднимает сервер только на `127.0.0.1`. Это безопасно, но другие компьютеры его не видят. Установленная, portable и Android-версии работают только с внешним сервером и не запускают собственный локальный сервер.

### Локальная сеть: один ПК — хост

1. На ПК-хосте запустите **`carnage.bat`**, пункт **5** («Сервер для локальной сети»). Сервер покажет адрес физического адаптера **без VPN**, например:
   ```
   http://188.234.161.207:3001
   ```
   Проверить IP отдельно можно пунктом **18** (или `npm run my-ip`). Адрес AmneziaVPN вида `172.16.0.2` клиентам не подходит.
2. При первом запуске разрешите Node.js доступ в **частных сетях** в запросе брандмауэра Windows. Если запрос не появился, создайте правило для входящего TCP-порта `3001`:
   ```powershell
   netsh advfirewall firewall add rule name="Carnage Party 3001" dir=in action=allow protocol=TCP localport=3001
   ```
   (командную строку нужно запустить от администратора)
3. Для текстового чата адрес можно открыть в браузере: `http://188.234.161.207:3001`.
4. Для **голоса, камеры и демонстрации экрана** браузеру нужен HTTPS: Chrome блокирует медиа на `http://IP`. Проще подключиться Electron-клиентом:
   - в portable-версии адрес сервера уже указан по умолчанию — просто запустите `Carnage-Party-Portable-1.2.3.exe`;
   - если адрес изменился, откройте в клиенте **Настройки → Сервер**, введите `http://<IP-хоста>:3001` и нажмите «Подключиться»;
   - либо запустите **`carnage.bat`**, пункт **6**, и введите адрес.
   Electron-клиент автоматически разрешает камеру/микрофон/экран для LAN-адреса.
5. Аккаунты, сообщения и файлы хранятся на ПК-хосте в папке `data\`.
6. Голос, видео и демонстрация экрана работают напрямую через WebRTC — сервер только передаёт сигналы подключения.
7. ПК-хост должен оставаться включённым, а окно сервера — открытым. Резервная копия — папка `data\`.
8. **Выключите AmneziaVPN перед запуском сервера.** При включённом VPN Windows добавляет маршрут по умолчанию через туннель, ответы уходят не через Ethernet, и физический IP `188.234.161.207` перестаёт открываться даже на самом ПК. Проверить можно так: `Test-NetConnection 188.234.161.207 -Port 3001` и `curl http://188.234.161.207:3001/api/health`.

Сервер можно запустить и вручную:

```powershell
set CARNAGE_HOST=0.0.0.0
set CARNAGE_PORT=3001
npm run server
```

Адрес сервера задаётся в приложении: **Настройки → Сервер**. При первом запуске portable-версия использует адрес, зашитый при сборке (физический IP хоста без VPN). Файл `server.txt` больше не нужен; если он остался от старой версии, portable его игнорирует. Если сервер переехал на другой IP, введите новый адрес в настройках и нажмите «Подключиться».

### Через интернет (VPS)

1. Разместите проект на сервере с Node.js 20+ (Windows или Linux).
2. Запустите сервер, слушая все интерфейсы:
   ```bash
   CARNAGE_HOST=0.0.0.0 CARNAGE_PORT=3001 npm run server
   ```
3. Поставьте reverse-proxy с HTTPS (Caddy или Nginx). Пример `Caddyfile`:
   ```
   chat.example.com {
       reverse_proxy 127.0.0.1:3001
   }
   ```
   Caddy автоматически проксирует WebSocket/Socket.IO и выдаёт сертификат.
4. Клиенты подключаются по `https://chat.example.com` — через браузер, `carnage.bat` (пункт 6) или в настройках «Сервер».
5. Для голоса и видео за NAT нужен **TURN-сервер** (например, coturn). STUN Google помогает, но не гарантирует соединение между сложными NAT.
6. Обязательно смените демо-пароли. Сейчас регистрация открыта — для публичного сервера стоит добавить инвайты или закрыть регистрацию.

### Безопасность

- `carnage.bat`, пункт 2 — сервер доступен только на этом ПК.
- `carnage.bat`, пункт 5 — доступен всем устройствам в локальной сети. Не используйте в общественных Wi-Fi.
- Для интернета — только HTTPS, сильные пароли и резервные копии папки `data`.
- VPN (Amnezia и др.) может блокировать входящие подключения к локальной сети. Разрешите LAN/loopback в настройках VPN или используйте белый список адресов.

## Проверка и диагностика

```powershell
npm run server      # в одном окне
npm run smoke       # в другом: 15 проверок API, SPA и Socket.IO
```

Smoke-тест использует демо-данные. Для чистой базы запустите сервер с `CARNAGE_SEED_DEMO=1`.

Проверка камеры, микрофона и демонстрации экрана (Electron с фейковыми устройствами):

```powershell
npx electron . --remote-debugging-port=9333 --use-fake-device-for-media-stream --use-fake-ui-for-media-stream
node scripts/voice-check.cjs
```

Фейковые камера, микрофон и зелёный «экран» используются **только** в этом автотесте. Обычный запуск через пункт 2 `carnage.bat` и установленную/portable-версию всегда работает с реальными устройствами и реальным экраном.

Скрипт проверит `getUserMedia`, `getDisplayMedia`, окно выбора монитора и кнопки голосовой комнаты, а также сохранит скриншоты `voice-check.png` и `voice-picker.png`.

Или запустите `carnage.bat`, пункт 17 — он покажет версии Node/npm, наличие зависимостей и занятость портов 3001, 5173, 32456.

## Решение проблем

**SmartScreen предупреждает о неизвестном издателе.** Установщик не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

**Антивирус блокирует portable.** Добавьте папку проекта или `release` в исключения.

**Порт занят.** Закройте старый экземпляр приложения или задайте `CARNAGE_PORT`. Проверить занятость: `carnage.bat`, пункт 17.

**Белый экран после запуска.** Пересоберите клиент: `carnage.bat`, пункт 7, затем пункт 2.

**Не работает вход.** Убедитесь, что сервер запущен и адрес в настройках верный. Сбросить данные: закрыть приложение и удалить `%APPDATA%\Carnage Party\data`.

**VPN (Amnezia, WireGuard и т.п.).** Не влияет на работу: приложение общается с `127.0.0.1` — петлевым адресом, который не идёт через туннель. Если VPN-клиент блокирует локальные подключения, разрешите loopback/LAN в его настройках.

**Микрофон или камера не работают.** Проверьте разрешения Windows: «Параметры → Конфиденциальность → Микрофон/Камера», разрешите доступ для Carnage Party.
