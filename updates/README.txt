Carnage Party — папка обновлений
================================

Положите сюда файлы новой версии. Сервер читает папку при каждом запросе
GET /api/version, перезапускать его не нужно.

Имена файлов строго такие:

  Carnage-Party-Setup-<версия>.exe      — установщик для обычной версии Windows
  Carnage-Party-Portable-<версия>.zip   — портативная версия (ZIP предпочтительнее EXE)
  Carnage-Party-Portable-<версия>.exe   — портативная версия одним файлом
  Carnage-Party-Mobile-<версия>.apk     — клиент Android

Пример:

  Carnage-Party-Setup-1.1.1.exe
  Carnage-Party-Portable-1.1.1.zip
  Carnage-Party-Mobile-1.1.1.apk

Версия — три числа через точку. Для каждой платформы сервер сам выбирает
файл с наибольшей версией.

Необязательно: создайте рядом файл notes.txt с текстом изменений — он
покажется в окне обновления.

Changelog по версиям — файл changelog.json:

  {
    "1.1.1": [
      "Добавлена проверка обновлений",
      "Исправлена мобильная вёрстка"
    ]
  }

Список для нужной версии показывается в окне обновления под заголовком
«Что нового». Если записи нет, используется notes.txt.

Клиент при запуске запрашивает /api/version и, если версия файла для его
платформы больше установленной, предлагает скачать обновление:

  - обычная версия Windows — установщик Setup;
  - портативная — ZIP (распаковать поверх папки);
  - Android — APK (versionCode должен быть больше установленного).

Если установленная версия работает на собственном локальном сервере,
обновления нужно положить сюда же:

  %APPDATA%\Carnage Party\updates

Файлы копируются вместе с changelog.json. Перезапуск приложения не нужен —
проверка выполняется при следующем запуске.
