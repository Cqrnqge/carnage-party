CARNAGE PARTY — ANDROID APK
==========================

Сборка
------
Запустите build-mobile.bat в корне проекта.

Скрипт:
- найдёт переносную Java (H:\l2j\classic 1.0\ClassicServer\java)
  или использует JAVA_HOME;
- при первом запуске скачает Android Build-Tools 35 и Platform 35
  в mobile\.sdk (около 120 МБ);
- соберёт и подпишет APK;
- положит результат в release\Carnage-Party-Mobile-1.1.0.apk.

Адрес сервера по умолчанию берётся из electron\default-server.txt
(сейчас http://188.234.161.207:3001). Можно передать свой:

  build-mobile.bat http://192.168.1.10:3001

Смена сервера в приложении
--------------------------
Настройки пользователя → Сеть → Сменить сервер.
Если сервер недоступен, при запуске появится экран с кнопкой
«Сменить сервер».

Возможности
-----------
- Тот же интерфейс, что и в desktop-версии (загружается с сервера).
- Текстовые каналы, личные сообщения, вложения, голосовые сообщения.
- Голосовая комната: микрофон и камера (Android WebView).
- Выбор файлов для вложений, скачивание файлов.
- Демонстрация экрана в Android WebView не поддерживается.
- Глобальная рация (PTT) работает только когда приложение открыто;
  ограничение Android, в фоне клавиши не перехватываются.

Подпись
-------
Ключ создаётся один раз в mobile\keystore\carnage-release.jks.
Не удаляйте его: без него нельзя выпустить обновление с тем же
package name. Пароль хранится в build-mobile.ps1.
